# Résultats légers

Ce dossier reçoit uniquement des synthèses suffisamment petites pour Git : tableaux agrégés, graphiques, conclusions et références vers les runs bruts. Les journaux détaillés, traces, bases et profils volumineux restent sur `D:\InferenceCompanionLab`.

Chaque synthèse doit indiquer :

- les identifiants des runs inclus et exclus ;
- la raison de chaque exclusion ;
- les versions et hachages pertinents ;
- les métriques primaires avec dispersion ;
- le contrat de fidélité ;
- les violations de QoS ;
- les coûts de préparation, transition, pause et reprise ;
- les limites de généralisation ;
- le résultat, y compris s’il est négatif.
