# Expériences versionnées

Un sous-dossier futur par expérience contiendra : hypothèse, protocole, petit code d’analyse, résultats synthétiques et conclusion. Les mesures brutes restent dans `D:\InferenceCompanionLab\results` et sont reliées par identifiants et hachages.

Une expérience doit annoncer avant exécution :

1. hypothèse ;
2. variables indépendantes et contrôlées ;
3. métriques primaires et secondaires ;
4. oracle de fidélité ;
5. budget de gêne ;
6. critères d’arrêt ;
7. critère de succès ;
8. critère d’abandon ou de reformulation ;
9. répétitions et analyse de variance ;
10. restauration et conservation des artefacts.

Le premier dossier attendu sera `exp-0001-observer-and-abcd` une fois le modèle, le moteur et la charge fixés.
